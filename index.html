    02 — STACK

    Production architecture

    Durable core

    • Event-sourced log in PostgreSQL
    • Write-ahead before every side effect
    • Redis locks, Kafka queues, DLQ

    Agentic AI

    • Planner, Exec, Critic agents
    • Schema-bound JSON, seed-locked
    • Human approval for destructive acts

    Vision and RAG

    • ONNX MobileNet inspection worker
    • pgvector hybrid retrieval, citations
    • RAM and CPU capped containers

    Zero-trust

    • OIDC, JWT, three RBAC roles
    • TLS 1.3, AES-256-GCM fields
    • Non-root, all capabilities dropped

    Frontend

    • React and Tailwind dashboard
    • Live updates over SSE
    • Light and dark, mobile first

    Operations

    • Docker Compose and Kubernetes
    • Idempotency key per attempt
    • Backpressure on replay
